### About

I’m a backend-focused developer who likes building practical systems: APIs,
service layers, database-backed applications, and internal tools.

My main language is **Go**, but I also work across the web stack with
**Python**, **TypeScript**, **React**, and **Next.js**. Outside product work, I
spend a lot of time refining my Linux/Neovim workflow and exploring lower-level
graphics programming with **Vulkan**.

I care about simple architecture, readable code, reliable systems, and tools
that make development faster.
